# CS Problem Solving

A collection of programming exercises focused on:

- algorithms
- logical reasoning
- problem solving
- low-level programming
- computational thinking

This repository contains solutions and experiments created during my computer science studies and practical software engineering training.

## Goals

The purpose of this repository is to:

- improve problem-solving skills
- practice algorithm implementation
- strengthen programming fundamentals
- document learning progress
- explore different approaches to computational challenges

## Topics

Some recurring topics include:

- string manipulation
- recursion
- memory management
- parsing
- sorting algorithms
- data structures
- mathematical problems
- optimization
- systems programming concepts

## Structure

Every exercise has its own dedicated directory containing:

* the original subject or problem statement
* the source code implementation
* supporting files when necessary

The goal is to maintain a clear and independent structure for each challenge, making it easier to revisit concepts, compare approaches, and track learning progress over time.


## Disclaimer

The exercises published here are intended for educational purposes only.
